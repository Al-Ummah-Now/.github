# Al Ummah Now · الأمة الآن

Al Ummah Now is an Islamic video and community platform, in English and Arabic.

Visit the site at **[www.alummahnow.net](https://www.alummahnow.net)**, watch at **[videos.alummahnow.net](https://videos.alummahnow.net)**, and sign in or manage your account through **[auth.alummahnow.net](https://auth.alummahnow.net)** and **[your profile](https://profile.auth.alummahnow.net)**.

## Our repositories

| Repository | What it does |
|---|---|
| [AlUmmahNow](https://github.com/Al-Ummah-Now/AlUmmahNow) | The videos platform: web, APIs, background processing, realtime and admin |
| [AlUmmahNowAuth](https://github.com/Al-Ummah-Now/AlUmmahNowAuth) | Single sign-on, account profile and auth admin |
| [openauth](https://github.com/Al-Ummah-Now/openauth) | Our fork of OpenAuth, the library behind sign-in |
| [AlUmmahNowUI](https://github.com/Al-Ummah-Now/AlUmmahNowUI) | The public website |
| [AlUmmahNowCMS](https://github.com/Al-Ummah-Now/AlUmmahNowCMS) | Content management for the website |
| [AlUmmahNowCore](https://github.com/Al-Ummah-Now/AlUmmahNowCore) | Shared Rust library for the native apps |
| [AlUmmahNowApple](https://github.com/Al-Ummah-Now/AlUmmahNowApple) | Apps for iPhone, iPad, Apple TV and Mac |
| [AlUmmahNowAndroid](https://github.com/Al-Ummah-Now/AlUmmahNowAndroid) | Apps for Android phones, tablets, TV and Auto |
| [AlUmmahNowDesktop](https://github.com/Al-Ummah-Now/AlUmmahNowDesktop) | Apps for Windows, Linux and Samsung TVs |
| [AlUmmahNowTools](https://github.com/Al-Ummah-Now/AlUmmahNowTools) | Bulk video import tools |

## Learn more

The **[Al Ummah Now Wiki](https://github.com/Al-Ummah-Now/AlUmmahNowWiki)** explains how the system fits together, with a page for every repository.

## Contribute or report a problem

- To suggest a change, read the [contributing guide](https://github.com/Al-Ummah-Now/AlUmmahNowWiki/blob/main/guides/contributing.md) and open a pull request.
- To report a bug or request a feature, open an issue in the repository concerned.
- To report a security problem, please don't open a public issue. Use **Security → Report a vulnerability** in that repository.
